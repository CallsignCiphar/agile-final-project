# Definition of Done

A user story is not marked Done unless all of the following are true:

1. Acceptance criteria on the GitHub Issue are met.
2. Code is committed to a feature branch and merged to `main` via pull request.
3. The feature works end to end locally (frontend and backend, where applicable) without console errors.
4. Basic input validation and error states are handled (no unhandled crashes on bad input).
5. Relevant docs are updated if the change affects setup, scope, or the backlog (README, PRODUCT_BACKLOG, or sprint plan).
6. The corresponding card on the GitHub Project board is moved to Done.

## Definition of Ready (for pulling a story into a sprint)

1. The story has a clear "As a ... I want ... so that ..." statement.
2. Acceptance criteria are written on the issue.
3. The story is estimated (story points).
4. There are no open blocking questions.
